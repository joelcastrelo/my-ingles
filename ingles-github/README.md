# Tu entrenador de inglés

Práctica con huecos, pistas y repaso de errores, más una biblioteca original en español con 41 temas de consulta. Funciona en móvil y ordenador.

## Abrir en tu ordenador

Mantén juntos index.html y library.js y abre index.html con doble clic. Las explicaciones y ejercicios funcionan sin conexión. Los enlaces a Espikin necesitan internet. El audio depende de las voces que ofrezca tu navegador.

## Publicar en GitHub Pages

1. Crea en GitHub un repositorio público, por ejemplo ingles.
2. Extrae el ZIP en tu ordenador.
3. En el repositorio selecciona Add file y Upload files.
4. Sube index.html, library.js y README.md directamente a la raíz del repositorio. No subas el ZIP.
5. Confirma con Commit changes.
6. Abre Settings y después Pages.
7. En Source elige Deploy from a branch.
8. Elige la rama main y la carpeta /(root), y pulsa Save.
9. Espera al despliegue. La dirección aparecerá en Pages, normalmente https://TU-USUARIO.github.io/ingles/.

Guía oficial https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Progreso en varios dispositivos

Los repasos pendientes y los borradores se guardan en el navegador. En Llevar mi progreso, pulsa Exportar progreso para guardar un JSON. En el otro dispositivo usa Importar copia JSON. La importación sustituye la copia local. GitHub Pages sirve la aplicación, y cada navegador conserva su propio progreso.

También puedes exportar desde tu versión local e importar en la versión publicada. Si usabas el archivo anterior, su progreso se podrá leer cuando el navegador comparta el almacenamiento de archivos locales. Conserva el archivo anterior hasta comprobar que tienes tus borradores.

## Contenido y alcance

La biblioteca contiene explicaciones y ejemplos originales de 14 temas gramaticales, 5 bloques de Use of English, 5 formatos de Writing, 3 estrategias de Reading, 2 de Speaking, una guía de Listening y 11 temas de vocabulario. Los 105 ejercicios iniciales y 76 variantes de frase constituyen un banco finito. Los niveles son orientativos. El writing incluye esquemas, un hueco de calentamiento, modelos y una lista de autoevaluación.

La biblioteca de vocabulario permite consultar las 30 palabras del banco de práctica. Los enlaces de cada tema permiten consultar el catálogo completo de Espikin. Las guías son introductorias y no contienen todas las explicaciones de esa web.

Espikin reserva la reproducción y distribución de sus textos a quienes cuenten con autorización expresa. Este proyecto incluye contenido didáctico original y enlaces. Para incorporar y redistribuir los textos íntegros se necesita autorización de su titular.

Fuente de los temas https://espikin.es/

Condiciones de Espikin https://espikin.es/aviso-legal.html

## Editar

index.html contiene el diseño, el banco de ejercicios y el motor de repaso. library.js contiene las explicaciones de consulta. No hay instalación de paquetes ni proceso de compilación.

Los JSON de progreso pueden contener tus borradores. Guárdalos en tus dispositivos para llevarlos de uno a otro.
